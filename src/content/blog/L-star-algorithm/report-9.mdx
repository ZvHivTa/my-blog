### 1. Terminology

#### **i)** Syntactic Monoid: 

For a language $L \subseteq \Sigma^*$, $w \in L$ and $w^{\prime} \in L$ is *syntactic congruence* when:

$$
\forall u,v \in \Sigma^* \space uwv \in L \Leftrightarrow uw^{\prime}v \in L
$$

We can use $u ∼_L v$ to describe this relation. 

Then we can use $∼_L$ divide $\Sigma^*$ into many classes, for example $[u]$ means every string which is syntactic congruence with $u$. In other words:

$$
u ∼_L v \Leftrightarrow v\in [u]
$$

Define $\cdot$ as the symbol of *binary operation* on these equivalence classes, then:

$$
[u]\cdot[v] = [uv]
$$

Then by this equivalence relation, the monoid $M(L)$ is the *Syntactic Monoid* of the language $L$ and we can say $M(L)$ recognize the language $L$. Also, $M(L)$ is the smallest transition monoid which recognize the language $L$ and it is the transition monoid of the *minimal DFA* which recognize the language $L$.

#### **ii)** unknown regular set: $U$

#### **iii)** Fixed alphabet: $\Sigma$

#### **iv)** Observation table( $OT$ ) :

Observation table( $OT$ ) is a 4-tuple $OT = (I,P,S,T)$ : 

① $I \subseteq \Sigma^*$ : prefix-closed infix set;

② $P\subseteq \Sigma^*$ : prefix-closed prefix set;

③ $S\subseteq \Sigma^*$ : suffix-closed suffix set;

④ $T$ is a function 

$$
T := (P\cdot( \Sigma \cdot I  \cup  I \cup I \cdot \Sigma) \cdot S ) \rightarrow \{0,1\}\\\\
$$

$T(u) = 1$  $\text{iff}$  $u$ is a member of $U$.

Observation table is initially set to $(\{\epsilon\},\{\epsilon\}\cup\Sigma,\{\epsilon\},T)$. This table can seen as a three-dimension array. 

The result is:

-  Elements of $I$ are the candidates for states of the syntactic monoid of $U$;

-  Elements of $P$ and  $S$  correspond to distinguishing experiments for these states.

-  Elements of $I \cdot \Sigma$ and $\Sigma \cdot I$ are used to construct the transition function. 


If 
$$
\forall p\in P,\forall s\in S, T(p\cdot i \cdot s) = T(p \cdot i^{\prime} \cdot s)
$$
It is observed that $i$ and $i^{\prime}$ are in the same status.

So here is a new definition:

⑤ $status$ is a function:
$$
status := (P \times S) \rightarrow \{0,1\}
$$
And 
$$
status_i(p,s) = T(p\cdot i \cdot s)
$$


This says: "The state for $i$, when given the pair $(p, s)$, is defined as the result of the membership query on the string $p·i·s$."

Then if 
$$
\forall p\in P,\forall s\in S, status_i(p,s) = status_{i^{\prime}}(p,s)
$$
Then we call $i$ and $i^{\prime}$ is $\text{status - equivalent}$ which denoted $i \equiv_{status} i^{\prime}$. And we use $[i]_{status}$ to represent that at the condition of this $status$ function word $i$ forms a equivalence class. Then obviously $[i]_{status} = [i^{\prime}]_{status}$

#### **v)** Acceptor:

If an observation table $OT = (I,P,S,T)$, then the acceptor of $(I,P,S,T)$ is a 6-tuples $\mathcal{M} = (Q,\Sigma,\delta,l/r,q_0,F)$ where

• $Q = \{status_i| i \in I\}$

• $q_0 = T(\epsilon) \in Q$

• $\{l,r\}$ is the mark of operations. We can also see $\Sigma_d = \Sigma \times \{l,r\}$ as an enhanced alphabet.

• $F = \{status_i \in Q|status(\epsilon,\epsilon) = 1\}$

• $\delta:Q \times \Sigma \times \{l,r\} \rightarrow Q$ is the transition function defined as $\delta(status_i,a,r) = status_{i \cdot a},\delta(status_i,a,l) = status_{a \cdot i}$. This is well-defined if the table is closed.

The transition function $\delta$ is extended to the function $\delta^{*}:Q \times (\Sigma\times\{l,r\})^{*} \rightarrow Q$:

$$
\delta^{*}(q,w) = 
\begin{cases}
q & \text{if} & w = (\epsilon,l/r) \\\\
\delta(\delta^*(q,w^{\prime}),a,d) & \text{if} & w = w^{\prime} \cdot(a,d) \space, \space a \in \Sigma,d \in \{l,r\}\\
\end{cases}
$$

A run is $\rho \in \Sigma_d^*$.  For example:
$$
\rho_1 = (a,l)(b,l)\\
\rho_2 = (b,r)(a,r)
$$
Actually this is all $w = ba$ but in this model both 2 runs can generate it.

So we define a mapping from enhanced string such as $u \in \Sigma_d^*$ to a normal string as $w \in \Sigma^*$, so we can have a canonical mapping $val: \Sigma_d^* \rightarrow \Sigma^*$ :


$$
val(\rho) =  
\begin{cases}  
\epsilon & \text{if } \rho = \epsilon \quad \\ 
a \cdot val(\rho') & \text{if } \rho = \rho' \cdot (a, l) \quad (\text{left operation}) \\ 
val(\rho') \cdot a & \text{if } \rho = \rho' \cdot (a, r) \quad (\text{right operation}) 
\end{cases}
$$
Then we can define a $Runs(w)$ :
$$
Runs(w) = \{ \rho \in \Sigma_d^* \mid val(\rho) = w \}
$$
this is the set of all runs which can generate $w$. 

And we can also use enhanced alphabet to define $\delta^*:Q \times \Sigma_d^{*} \rightarrow Q$, then:
$$
\delta^{*}(q,\rho) = 
\begin{cases}
q & \text{if} & \rho = (\epsilon,l/r) \\\\
\delta(\delta^*(q,\rho^{\prime}),(a,d)) & \text{if} & \rho = \rho^{\prime} \cdot(a,d) \space, \space a \in \Sigma,d \in \{l,r\}\\
\end{cases}
$$


#### vi) Membership queries: 

The learner selects a word $w \in \Sigma^{*}$ and the teacher gives an answer whether or not $w \in L$.

#### vii) Equivalence queries:

When the $OT$ is closed, we can get a hypothesis automaton $\mathcal{M}$ according to the acceptor, and the teacher answers whether or not $L$ is the language of $\mathcal{M}$. If the answer is yes, then the algorithm terminates. If no, then the teacher gives a counterexample, which differs $L$ from the language of $\mathcal{M}$.

### Separability and Closedness

Actually at each step of the algorithm, the learner maintains:

- A set $I \subseteq \Sigma^{*}$ of access words, with $\epsilon \in I$
- A set $P \subseteq \Sigma^*$ of prefix test words.
- A set $S \subseteq \Sigma ^{*}$ of suffix test words.

On the $(I,P,S)$ we can define:

- **Separability**: no two distinct words in $I$ are $\text{status-equivalent}$. 
- **Closedness**: for every $i ∈ I$ and $a ∈ Σ$, there is some  $i^{\prime},i^{\prime\prime}∈ I$ such that $ia ≡_{status} i^{\prime},ai ≡_{status} i^{\prime\prime}$

If $(I, P , S)$ is separable and closed then we can define a hypothesis automaton $\mathcal{M}$, according to the definition of acceptor and the propositions as follow.

**Proposition 1. (Minimal)** *If $(I,P,S)$ is separable then $|I|$ is at most the number of states of a syntactic monoid for $L$.*

According to the definition of Separability, we can assume each $i \in I$ is related to a $status_i$ which means $[i]_{status}$ is a equivalence class defined by $P$ and $S$.   

According to the definition of syntactic monoid, $u ∼_L v \Rightarrow [u] = [v]$.

Assume that now there is an acceptor $\mathcal{M} = (Q,\Sigma,\delta,l/r,q_0,F)$ and the language of $\mathcal{M}$ is $L_{\mathcal{M}}$. Because  $(I,P,S)$ is separable, in other words : 
$$
\forall u,v \in I.  u \equiv_{status} v \leftrightarrow(\forall p\in P, s \in S. (p\cdot i_1 \cdot s \in L_{\mathcal{M}}) \space \wedge \space (p\cdot i_2 \cdot s \in L_{\mathcal{M}}))
$$
So actually using the information we get now, we can know $[u]_{status} = [v]_{status}$. Under the status function, the minimal number of syntactic monoid is at most $|I|$. 

And in the contrary, if now $u \not\equiv_{status} v$, then $[u]_{status} \ne [v]_{status}$, in the future learning process $[u] \ne [v]$ in other words $u \not∼_L v$ is always correct. 

So the proposition is correct.

**Proposition 2. (Closedness)** If $(I,P,S)$ is separable but not closed, then using membership queries one can find $i^{\prime} \in I \cdot \Sigma^*$ such that  $(I ∪ {i^{\prime}}, P,S) $ remains separable.

Obviously, according to the definition of closedness, there exists $i^{\prime} \in I \cdot \Sigma$  :
$$
\forall i \in I. i \not\equiv_{status} i^{\prime}
$$
We should add this $i^{\prime}$ into $I$ so that we try to make it separable. 

**Proposition 3. (Counterexample)** Suppose that $(I,P,S)$ is separable and closed. Let $\mathcal{M} = (Q,\Sigma,\delta,l/r,i_0,F)$ be the hypothesis automaton. Given a counterexample $w = w_1 . . . w_n$ to $\mathcal{M}$, using membership queries, one can find $i ∈ Σ^∗ \ I$ and $s ∈ Σ^∗$ such that $(I ∪ {i}, S ∪ {s})$ is separable. 

**Proof.** Let $i_0 = ε$ be the initial state of $\mathcal{M}$. For $k = 1, . . . , n$, define $q_k = \delta(i_0, w_1 . . . w_k)$ to be the state reached by $\mathcal{M}$ after reading the prefix $w_1 . . . w_k$ of $w$. 

Writing $χ_L$ for the characteristic function of the target language L:
$$
χ_L(w) = 
    \begin{cases}
    0 & \text{if}\space w \notin L \\\\
    1 & \text{if} \space w \in L
    \end{cases}
$$
We say that state $i_k$ is correct if $χ_L(i_kw_{k+1} . . . w_n) = χ_L(w)$. Note that correctness of $i_k$ can be checked with a membership query. 

Now state $i_0 = ε$ is obviously correct.

State $i_n$ is not correct since $w$ is a counterexample and hence $χ_L(i_n) \neq χ_L(w)$ by definition of the set of accepting states of $\mathcal{M}$. Thus, we can find $k$ such that $i_{k−1}$ is correct and $i_{k}$ is not correct, that is,
$$
χ_L(i_{k−1}w_i. . . w_n) \neq χ_L(i_{k}w_{i+1} . . . w_n).
$$
Now let $I^{\prime} = I ∪ {i_{k−1}w_i}$ and $S^{\prime} = S ∪ {w_{i+1} . . . w_n}$. By definition of closedness, $i_k$ is the unique element of $I$ that is $\text{status-equivalent}$ to $i_{k−1}w_i$ . And the new suffix $w_{i+1} . . . w_n$ distinguishes $i_k$ from $i_{k−1}w_i$ . We conclude that $i_{k−1}w_i \notin I$ and that the new $OT$ is separable.

**Proposition 4. (Correctness)** *Assume that $(I,P,S)$ is closed and separable observation table and the algorithm terminated. Then the acceptor $\mathcal{M} = (Q,\Sigma,\delta,l/r,q_0,F)$ is the syntactic monoid of the language $L$.*

**Proof:**

Actually we want to prove this conclusion:

$$
\delta^*(q_0,w)=\delta^*(q_0,w') \Leftrightarrow \forall u,v ∈ Σ^*, (uwv ∈ L \text{ iff } uw^{\prime}v ∈ L)
$$

for the acceptor $M = (Q,\Sigma,\delta,l/r,q_0,F)$. Here $w$ is extended into string like $(a,l/r)(b,l/r)\cdots$.

From assumption we know some facts:

**a.** The algorithm terminated. There is no counterexample to make the $OT$ extend.

**b.** Because the observation table is consistent, then for $i_1,i_2 \in (I \cup I \cdot \Sigma \cup \Sigma \cdot I)$

If $i_1 \equiv_{status} i_2$, then $a\cdot i_1 \cdot b \equiv_{status} a\cdot i_2 \cdot b$, which $a,b \in \Sigma \cup \{\epsilon\}$.

① $\forall u,v ∈ Σ^*, (uwv ∈ L \text{ iff } uw^{\prime}v ∈ L) \Rightarrow \delta^*(q_0,w)=\delta^*(q_0,w')$ is clear. 

Because now $[w] = [w^{\prime}]$, then we can know $w \in L \Leftrightarrow w^{\prime} \in L$, which is equal to $\delta^*(q_0,w)=\delta^*(q_0,w')$

② Prove $\delta^*(q_0,w)=\delta^*(q_0,w') \Rightarrow \forall u,v ∈ \Sigma^*, (uwv ∈ L \text{ iff } uw^{\prime}v ∈ L)$

This is clear:
$$
\exists i \in I, \delta^*(q_0,w) = \delta^*(q_0,w') = status_i
$$

$$
\forall  a,b \in \Sigma \cup \{\epsilon\}. \delta(\delta^*(q_0,w),a,l) = \delta(\delta^*(q_0,w'),a,l)\\
$$

Then we have $\delta(\delta^*(q_0,aw),b,r) = \delta(\delta^*(q_0,aw'),b,r)$. It is same if we add $b$ at right side first.

So we actually have $\delta^*(q_0,awb) = \delta^*(q_0,aw'b)$, it is also means:

$$
    \forall  a,b \in \Sigma \cup \{\epsilon\}. a\cdot w\cdot b \equiv_{status} a\cdot w'\cdot b
$$

Returning to the mathematical induction mentioned earlier, so when $|u| = |v| = 0$ and $|u| = |v| = 1$, $(uwv ∈ L \text{ iff } uw^{\prime}v ∈ L)$ is clear.

When $|u| = k$ and $|v| = l$, assume $(uwv ∈ L \text{ iff } uw^{\prime}v ∈ L)$ is true. It means $\delta(q_0,uwv)=\delta(q_0,uw^{\prime}v)$. 

$$
\exists i^{\prime} \in I, \delta(q_0,uwv) = \delta(q_0,uw^{\prime}v) = status_{i^{\prime}} = status_{uwv} = status_{uw^{\prime}v}
$$


Then according to the discussion, we can also know:

$$
\forall a,b \in \Sigma \cup \{\epsilon\}. status_{a\cdot uwv\cdot b} = status_{a\cdot uw^{\prime}v\cdot b}
$$

So for 
$$
|u| = k+1 \text{ and } |v| = l\\
     |u| = k \text{ and } |v| = l+1\\
     |u| = k+1 \text{ and } |v| = l+1\\
$$

all these three conditions, the conclusion is clear.

Then we can actually know ② is correct and the whole conclusion is correct. 

**Proposition 5. (Acceptor)** If we get an acceptor $\mathcal{M} = (Q,\Sigma,\delta,l/r,q_0,F)$ (hypothesis automaton) in our algorithm, a $w$ which can be generated by different runs can be only transform in only one state. 
$$
\forall w \in \Sigma^*, \quad \forall \rho_1, \rho_2 \in Runs(w) \implies \delta^*(q_0, \rho_1) = \delta^*(q_0, \rho_2)
$$
Assume that there is a $w = a_1a_2\cdots a_n$, it has 2 run $\rho_1$ and $\rho_2$ go into the different states, in other words $\delta^*(q_0, \rho_1) \neq \delta^*(q_0, \rho_2)$. 

But $\delta^*(q_0, \rho_1) \neq \delta^*(q_0, \rho_2)$, then let's assume $\delta^*(q_0, \rho_1) = q_1$  and $\delta^*(q_0, \rho_2) = q_2$. So as we know, we can definitely find $i_1 \in I, status_{i_1} = q_1$ and  $i_2 \in I, status_{i_2} = q_2 $ . 

So $[w] = status_{i_1} = status_{i_2}$, this is contradiction because $\delta^*(q_0, \rho_1) \neq \delta^*(q_0, \rho_2)$ means $status_{i_1} \neq status_{i_2}$. 

### 2. Process of Algorithm


Initialize $I$ and $S$ to $\{\epsilon\}$.

Initialize $P$ to $\{\epsilon\} \cup \Sigma$.

**Repeat:**

While $OT$ is not closed but separable: 

​       Find $i^{\prime} \in I \cdot \Sigma$ which is different with any $status_{i}, i \in I$. 

​       Add $i^{\prime}$ to $I$ and renew the $I\cup \Sigma$, in other words, add $i^{\prime}\cdot a$ to $I\cdot \Sigma$ for all $a \in \Sigma$. 

Repeat ① until $OT$ is closed. 

**********

Once $OT$ is closed and separable, let acceptor $M$ be the result and let Teacher find counterexample $t$, if $t$ is a counter-example:

Use Proposition 3 to deal with the situation. 

Check all the $\text{status-equvalence}$ pairs again. 

**Attention:** After dealing with counterexample, we must renew the $\text{status-equvalence}$ relations. You can't use the old relations under out of date information. 

**********

Use membership query to check new element in $P\cdot (\Sigma \cdot I \cup I \cup I \cdot \Sigma) \cdot S$. 

Until the Teacher replies yes to acceptor $\mathcal{M}$.

Stop and output $\mathcal{M}$.

### 4. Time analysis

Because the structure of $U$ is unknown, so the time complexity depends on the number of counterexample and the number of the states of $U$. Then we use $m$ to represent the number of counterexample, $|w|$ to represent the length of counterexample and $n$ to represent the number of states. And we use $k$ to represent $|\Sigma|$. 

The time complexity of the algorithm arises primarily from two operations: (1) maintaining the closedness of the observation table $OT$, and (2) processing counterexamples.

1. **Maintenance of Closedness** Whenever the observation table $OT$ is found to be non-closed, an element is added to the set $I$. Upon termination, $|I| = n$. Due to redundancy in string calculations, the set of extended rows is bounded by $|I\cdot \Sigma \cup \Sigma \cdot I| \le 2kn$. Furthermore, under Proposition 3, the size of $P$ remains constant as elements are only added to $S$. Consequently, the observation table consists of $(2k+1)n$ rows and $k(m+1)$ columns, yielding a total table size of:
$$
(2k+1)nk(m+1)
$$
   
2. **Counterexample Processing** For each counterexample found, a distinguishing suffix is identified in $O(\log|w|)$ time. Given $m$ equivalence queries, the total cost for this phase is $O(m\log|w|)$.

**Conclusion**

It is important to note that $m \le n$, as each counterexample reveals a lack of closedness in the table, which is an identification of a new candidate state. Therefore, substituting $m$ with $n$, the overall time complexity is:
$$
O(k^2n^2 + n\log|w|)
$$
