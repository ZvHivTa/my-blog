## 什么是敬语

敬语是日语中用来表达尊敬、谦逊和礼貌的语言形式。它在日本文化中非常重要，尤其是在正式场合、商务交流和与长辈或上司的对话中。

敬语的分类方式很多，《标准日语语法》主要分为四类：

1. 尊敬语（そんけいご）：用来表达对对话中提及的人（他的行为、状态以及属于他的事物）的尊敬，这个人通常可以是听话人或者说话人以外的第三者。

2. 谦让语（けんじょうご）：用来表达对说话人自己的行为、状态以及属于说话人的事物的谦逊，从结果上看还是对对方的尊重。

3. 丁寧語（ていねいご）：用来表达对听话人的礼貌，主要通过使用敬体（です、ます）来实现。从待遇文体上讲，丁寧語就是敬体。

4. 美化語（びかご）：用来表达对事物的美化，主要通过在名词前加上お或者ご来实现。它并不直接表达对人的尊敬，而是通过提高说话人的品味来间接表达对听话人的尊敬。

接下来我们分门别类地介绍一下这四类敬语的用法和例子。

## 尊敬语（そんけいご）

### 尊敬语的用法

1. 尊称尊敬对象以及属于该方的人物
2. 尊称尊敬对象的行为或存在
3. 尊称尊敬对象的性质状态
4. 尊称尊敬对象的事物

但要注意几个情况：

1. 句子的主体，如果是物品、宠物时，即使属于长辈的东西，也不使用尊敬语。

例：

ー　社長の家には犬がいます。　（社长家里有只狗。）（○）

ー　社長の家には犬がいらっしゃいます。　（×）

2. 对于历史人物，基本不使用敬语。

例：

ー　織田信長は戦国時代の有名な武将です。　（织田信长是战国时代的著名武将。）（○）

ー　織田信長さんは戦国時代の有名な武将。　（×）

3. 固定词组中的词语，不能用敬语代替。

例：

ー　住めば都（○）

ー　お住みになれば都（×）

4. 注意待遇要一致，不能把敬语和粗俗词语混杂在一块。

例：

ー　美味しいですから、お食いになってください。　（因为很好吃，请吃吧。）（ｘ）

ー　美味しいですから、召し上がってください。　（○）

### 体言的尊敬语

1. 本身就是尊敬语的体言

常见的比如：あなた、どなた；このかた、そのかた、あのかた、どのかた；こちら、そちら、あちら、どちら；先生、社長、部長、店長、教授等。

例：

ー　そのかた　はわたくしの恩師（おんし）です。　（那位是我的恩师。）

ー　さきほど　常務　がお見えになりました。　（刚才常务来了。）

2. 通过前缀或者后缀来构成的尊敬语

常见的前缀有：お、おん、み、う；常见的后缀有：様（さま）、さん、殿（どの）、氏（し）、がた。

例：

ー　お母様はお元気ですか。　（您母亲身体好吗？）

ー　ちょっとお時間よろしいですか。　（请问您有时间吗？）

ー　ご都合いかがでしょうか。　（请问您方便吗？）

ー　先生がたもうすぐお見えになります。　（老师们也快来了。）

ー　あの方がたのご意見をお聞かせください。　（请听听那位们的意见。）

还有同时使用前缀和后缀的情况，比如：お・ご＋体言＋様（さま）・さん

例：　ご主人さま。お医者さん。お嫁さん。お父様。お母様。お兄様。お姉様。お子様。お客様。

当然实际使用中也有许多说法，接下来终点介绍几个:

1. **あなた**

日语中表示“你”的词汇非常丰富，而且它们的发展史几乎都遵循着一个极其有趣的语言学规律：“词义贬值”（也叫“敬意递减”）。也就是说，很多现在听起来很随意甚至粗鲁的词，在古代其实是极其尊敬的说法。

「あなた」写成汉字是「彼方」或「貴方」。它的演变非常具有代表性：

* **奈良 / 平安时代：表示“方向”或“远方”**
    * **用法：** 纯粹的指示代词（与「こなた / 这边」相对），与人称无关。
* **中世（镰仓/室町时代）：指代“第三人称”**
    * **用法：** 开始用来指代人，即“他/她”。
    * **敬意：** 带有一定的尊敬意味。
* **江户时代：演变为“第二人称”**
    * **用法：** 开始被武家或富裕町人阶层的女性用来称呼对方。
    * **敬意：** **极高**，相当于中文里的“您”。
* **明治时代至今：敬意下降，趋于平级或向下**
    * **用法 ①：** 随着近代化，被确立为英语“you”的标准化翻译。
    * **用法 ②：** 成为妻子称呼丈夫（类似于“亲爱的”）的专属词汇。

    
所以现代日语中：

**对上级/长辈：绝对不可使用。**

对平级/下级：可以使用。 但有时会显得生疏或带有说教意味。

问卷调查/广告语：广泛使用。 因为面对的是不特定的群体，此时「あなた」是一个中性的虚拟代词。

夫妻之间： 妻子对丈夫使用，带有亲昵感。

在现代日语中，最尊敬、最自然的“你”，是不使用代词，而是直接称呼对方的「姓氏 + 职位/さん」（例如：田中先生、佐藤部長）。

关于其他的“你”的表达方式：

① 君（きみ / Kimi）：敬意较低。原指代天皇、君主。
现在通常是男性对平级或下级使用，或者用于歌词中营造文艺、青春的氛围。女性较少在口语中使用

② お前（おまえ / Omae）：敬意最低。指神明、佛像或贵人所在的前方。
通常是男性对平级或下级使用，或者在非常亲密的关系中使用（例如：兄弟、情侣）。女性几乎不使用。

③ 貴様（きさま / Kisama）：原本是非常尊敬的说法，武士阶层用来称呼值得尊敬的对手。
但现在已经完全变成了侮辱性的词汇，绝对不可使用。

④ 手前（てめえ / Temee）：原本是非常尊敬的说法，原本是谦辞，指“自己”（我），后来演变为“我面前的你”。
但现在已经变成了非常粗鲁的词汇，绝对不可使用。

2. 方位指示代名词

例如：こちら、そちら、あちら、どちら 这些用来指代人时，比较委婉，可用在平辈和晚辈。

如果后面加上了様（さま）或者さん，那么尊敬程度就更高了。

3. 关于「お」和「ご」

需要注意几点：

① 区分什么时候用「お」，什么时候用「ご」，最核心的规则是词源分类法：和语用「お」，汉语用「ご」

也就是「お」 ＋ 和语词（训读词），「ご」 ＋ 汉语词（音读词）

例如：お水（みず）、お金（かね）、お名前（なまえ）、お仕事（しごと）、お話し（はなし）。

ご家族（かぞく）、ご連絡（れんらく）、ご案内（あんない）、ご注意（ちゅうい）、ご意見（いけん）。

② 有一些汉语词因为在老百姓的日常生活中使用频率太高，已经“和语化”了，
所以大家习惯在前面加「お」而不是「ご」。这些词只能加「お」，加「ご」反而算错。

お電話（电话）、お食事（吃饭）、お時間（时间）、
お料理（料理）、お写真（照片）、お茶（茶）、
お化粧（化妆）、お掃除（打扫）、お風呂（洗澡）、
お誕生日（生日）、お仕事（工作）

总结一下就是：吃喝拉撒、生活琐事相关的汉语词，通常加「お」，而不是「ご」。

③ 外来语（片假名）原则上什么都不加

比如：テレビ（电视）、コンピュータ（电脑）、エアコン（空调）
这种外来语原则上不加「お」或者「ご」。

④ 自然现象、公共事物通常不加

太宏大的、太自然的东西，通常无需美化。

お雨（雨）、お空（天空）、お山（山）、お海（海）、お花（花）、お月様（月亮）

都不正确。

4. 様（さま）、さん、殿（どの）、氏（し）、がた 这几个后缀

① さん：现代日语中使用频率最高、最普适的尊称。

使用对象： 平级、晚辈、日常接触的长辈、邻居、同事。

适用场景： 口语和非正式书面语皆可。男女老少通用。

特殊用法： 接职业/店铺： 可以接在某些职业或店铺后面使其人格化，显得亲切。例如：本屋さん（书店老板）、運転手さん（司机师傅）。

接动植物： 小孩或女性有时会用来称呼动物，如：象さん（大象先生）。

⚠️ 禁忌： 绝对不能用于自己。（不能说：私は田中さんです✖️）

② 様（さま - Sama）：商务与正式场合使用的最高级别的敬称。

「様」是比「さん」敬意高得多的称呼，带有强烈的“将对方奉为上宾”的意味。

使用对象： 客户、未曾谋面的长辈、极其尊敬的人。

适用场景： * 商务邮件/信件： 收件人姓名后必须加「様」（例如：田中様）。

服务业： 店员对顾客的绝对称呼（お客様 - Okyakusama）。

账单/收据： 写抬头时使用（宛名：〇〇様）。

⚠️ 禁忌： * 不能接在职位后面： 日语的职位本身就带有敬意。
可以说「田中部長」，不能说「田中部長様」✖️。
如果非要连用，正确的语序是「部長 田中様」。

③ 殿（どの - Dono）

虽然古代叫“主公”就是「殿」，但在现代社会，乱用「殿」是非常失礼的。

现代核心规则：自上而下的称呼。

适用场景：

官方/公文： 机关单位发给个人的公文、表彰状、奖状、任命书上（因为发文机关在地位上视为高于或等于接收者）。

公司内部（老派公司）： 上级对下级发出的正式通知。

⚠️ 禁忌： 绝对不要对上司、长辈或客户使用「殿」。 
如果你给老板发邮件写「社長殿」，老板会认为你极其狂妄，居高临下。

④ 氏（し - Shi）：客观冷静的“第三人称”

「氏」带有很强的书面、客观和学术色彩，它不包含个人感情，只是一个中性的尊称。

使用对象： 新闻报道中的当事人、学术论文中的作者、不认识的第三方。

适用场景： * 新闻与媒体： 新闻播报时称呼某人（例如：山田氏によると… / 据山田先生说…）。

学术/公文： 在论文或客观报告中指代某个人。

⚠️ 禁忌： 不要在面对面的口语交际中使用。 
你不能看着对方的脸叫他「山田氏」，这会显得你像个没有感情的机器人或者在进行严肃的审讯。

⑤ がた（方 - Gata）：表示尊敬的“复数化”

它是一个非常正式的复数化后缀，表示对一群人的尊敬。

适用场景： * 皆様（みなさま）： 各位、大家（最常见的用法）。

先生方（せんせいがた）： 各位老师（比“先生たち”敬意高得多）。

あなた方（あなたがた）： 你们（用于对长辈或客户群体，比“あなたたち”礼貌）。

⚠️ 禁忌： 只能接在表示人的名词或代词后面，且该名词代表的对象必须是值得尊敬的。不能说「学生方」✖️，应该用「学生たち」。


### 动词的尊敬语

1. 使用尊敬动词

这些动词的原形式一般平时很常见，对应的尊敬动词有特定形式。

| 基础动词 (字典形) | 尊敬语 (特殊形式) | 常见使用场景 / 例句 |
| :--- | :--- | :--- |
| **行く / 来る / いる** | いらっしゃる / おいでになる | 社長は会議室にいらっしゃいます。（社长在会议室。） |
| **言う** | おっしゃる | お客様がおっしゃる通りです。（正如客户您所说。） |
| **食べる / 飲む** | 召し上がる（めしあがる） | どうぞお召し上がりください。（请享用。） |
| **見る** | ご覧になる（ごらんになる） | 添付の資料をご覧ください。（请查阅附件资料。） |
| **する** | なさる | 週末はどうなさいますか？（您周末打算做什么？） |
| **知っている** | ご存知だ（ごぞんじだ） | その件についてご存知ですか？（您知道那件事吗？） |
| **くれる** | くださる | 先生が本をくださいました。（老师给了我一本书。） |

2. 使用「お + ます形 + になる」的尊敬表达

对于没有1中提到的那些特殊形式，就可以采用这种方式表达。

比如：

* 書く → お書きになる 

社長がこの本をお書きになりました。（社长写了这本书。）

* 探す → お探しになる

お客様、何をお探しになりますか？（客户，您在找什么？）

* 確認する → ご確認になる

ご確認いただけますか？（您能确认一下吗？）

* 注文する → ご注文になる

ご注文いただけますか？（您能下单吗？）

当我们想请对方做某事的时候，就可以把「になる」换成「ください」了。

3. 被动形式「れる / られる」表示尊敬

这个更加的常见且保险。

* 一类动词：词尾变 あ段 + れる

* 二类动词：词尾 去掉る → られる

* 三类动词：する → される；来る → 来られる

例如：

- 部長は明日アメリカへ行かれます。（部长明天要去美国。）

- 先生はさっき帰られました。（老师刚才回去了。）


4. 状态与结果的尊敬「お / ご +动词ます形（去掉ます）/ 名词+ です」

它实际上属于「お + ます形 + になる」一种变体，主要用于表达动作正在进行或者动作完成后的状态。

* 帰る（回去了的状态）→ 社長はもうお帰りです。（社长已经回去了。）

* 休む（正在休息的状态）→ 部長は今お休みです。（部长现在正在休息。）

5. 变换动词以使用「お + ます形 + になる」

这些属于是比较特殊，无法生搬硬套使用「お + ます形 + になる」的动词，虽然形式一样，但是动词是完全不同的。

这通常是因为原动词只有一个音节（如「見る」「着る」，如果直接加「お」会非常别扭），或者原动词的意思太露骨、太直接（如「死ぬ」「寝る」「買う」）。

以下是几个最典型的“改变动词词干”的例子：

睡觉：寝る（ねる） ➡️ 替换为：休む（やすむ）
* ✖️ 错误套用：お寝になる（发音极度别扭）
* 🟢 正确形式：**お休みになる**（おやすみになる）
* 💬 例句：社長はもう**お休みになりました**。（社长已经就寝了。）

看：見る（みる） ➡️ 替换为：覧（らん - 汉语名词）
* ✖️ 错误套用：お見になる
* 🟢 正确形式：**ご覧になる**（ごらんになる）
* 💬 例句：この資料はもう**ご覧になりました**か？（这份资料您看过了吗？）
* *注：这里不仅换了词，前缀也因为「覧」是音读汉字而换成了「ご」。*

买：買う（かう） ➡️ 替换为：求める（もとめる）
* ⚠️ 直接套用：お買いになる（语法没错，但在百货公司等高级服务业略显不够优雅）
* 🟢 高级形式：**お求めになる**（おもとめになる）
* 💬 例句：チケットはあちらの窓口で**お求めになります**。（门票请在那边的窗口购买。）

穿衣：着る（きる） ➡️ 替换为：召す（めす）
* ✖️ 错误套用：お着になる
* 🟢 正确形式：**お召しになる**（おめしになる）
* 💬 例句：よく**お召しになる**ブランドは何ですか？（您常穿的品牌是什么？）

死亡：死ぬ（しぬ） ➡️ 替换为：亡くなる（なくなる）
* ✖️ 错误套用：お死にになる（绝对禁忌，太直接、太晦气）
* 🟢 正确形式：**お亡くなりになる**（おなくなりになる）
* 💬 例句：山田先生が昨日**お亡くなりになりました**。（山田老师昨天过世了。）


### 形容词/副词的尊敬语

表一：お ＋ 和语形容词（本土词，多为「い形容词」）

| 尊敬语形式 | 原形 | 核心含义 | 典型应用场景 / 常用句型 |
| :--- | :--- | :--- | :--- |
| **お忙しい** *(おいそがしい)* | 忙しい | 忙碌的 | **万能缓冲语：**「**お忙しい**ところ申し訳ありません」（百忙之中打扰您非常抱歉） |
| **お早い** *(おはやい)* | 早い | 早的、迅速的 | **感谢对方效率高：**「**お早い**お返事、ありがとうございます」（感谢您这么快回复） |
| **お若い** *(おわかい)* | 若い | 年轻的 | **赞美长辈保养得宜：**「社長はいつも**お若く**見えますね」（社长您看着总是这么年轻） |
| **お優しい** *(おやさしい)* | 優しい | 温柔的、和善的 | **夸赞对方的人品或态度：**「先生の**お優しい**お言葉に感謝します」（感谢老师温柔的话语） |
| **お美しい** *(おうつくしい)* | 美しい | 美丽的 | **赞美女性的外貌或举止：**「今日のお着物姿、とても**お美しい**です」（您今天穿和服的样子真美） |
| **お強い** *(おつよい)* | 強い | 强大的、酒量好的 | **赞美对方的能力或酒量：**「お酒が**お強い**んですね」（您酒量真好啊） |
| **お暑い / お寒い** *(おあつい/おさむい)* | 暑い / 寒い | 热的 / 冷的 | **季节性寒暄（关心对方）：**「**お暑い**中、ご苦労様です」（大热天的您辛苦了） |
| **お寂しい** *(おさみしい)* | 寂しい | 寂寞的 | **共情对方的情感：**「ご友人が帰国されて、**お寂しい**ですね」（朋友回国了，您一定觉得寂寞吧） |

| **ご親切** *(ごしんせつ)* | 親切 | 热心的、亲切的 | **感谢对方的帮助或指导：**「**ご親切**に教えていただき、感謝いたします」（感谢您热心指导） |

## 谦让语（けんじょうご）

谦让语是通过压低自己（或自己人）的动作和地位，来间接抬高对方。被尊敬的对象通常是听话人或者说话人以外的第三者。
谦让语的使用场景主要有两种：

1. 在句子中或者上下文中明确提到这个尊敬对象是谁。说简单点就是"捧人"。
这类叫做甲类谦让语。

2. 没有特定的尊敬对象，单纯是表达谦逊的态度，让听我说话的人觉得我很有教养。
这类叫做乙类谦让语。

### 甲类谦让语

| 动词类型 | 变形规则 / 特殊词汇 | 动作解析（靶子是谁？） | 实战场景演示 |
| :--- | :--- | :--- | :--- |
| **公式：和语** | **お** + 动词ます形 + **する/いたす** | 帮你拿行李、为你说明 | その重いお荷物は、私が**お持ちいたします。**（那个重行李，由我来帮您拿吧。靶子：您） |
| **公式：汉语** | **ご** + 动词词干 + **する/いたす** | 为你带路、联系你 | 後ほど改めて**ご連絡いたします**。（稍后我会再联系您。靶子：您） |
| **行く / 来る** | **伺う** (うかがう) | 去拜访（某人/某公司） | 明日、10時に面接に**伺います**。（明天10点我去贵公司面试。靶子：贵公司） |
| **言う** | **申し上げる** (もうしあげる) | 对（某人）说 | 担当者から**申し上げます**。（由负责人向您说明。靶子：您） |
| **見る** | **拝見する** (はいけんする) | 看（某人的）东西 | 募集要項を**拝見しました**。（我拜读了贵司的招聘启事。靶子：贵公司） |
| **聞く** | **伺う** (うかがう) / **承る** (うけたまわる) | 听（某人）说、接受（某人的）请求 | 要件は確かに**承りました**。（您的要求我确实听明白了。靶子：您） |

### 乙类谦让语

| 动词类型 | 变形规则 / 特殊词汇 | 动作解析（为什么没有靶子？） | 实战场景演示 |
| :--- | :--- | :--- | :--- |
| **する** | **いたす** | 我自己做某事（不针对人） | ソフトウェアエンジニアを目指して、日々勉強**いたしております**。（我正以成为软件工程师为目标，每天努力学习。） |

## 丁寧語（ていねいご）

丁寧語是通过使用敬体（です、ます）来表达对听话人的礼貌。
它是日常交流中最基本的敬语形式，适用于大多数正式和非正式场合。
但是要注意：它不涉及谁地位高、谁地位低，它的主要作用是拉开人与人之间的“社交安全距离”，向听话人展示你的教养和礼貌。

最标准的丁寧语，主要体现在句子的结尾。核心三大法宝是：「です」、「ます」、「でございます」。
